# ตลาดเช้าแม่ทิพย์

## โครงสร้าง

- `index.html` หน้าสั่งซื้อของลูกค้า รองรับลิงก์ร้าน `?id=s_xxxx` และลิงก์เดิม `?shop=ชื่อร้าน`
- `admin.html` แดชบอร์ดจัดการรอบตลาดและข้อมูลร้านค้า
- `admin-components/` เก็บค่าตั้งต้น สถานะ คอมโพเนนต์แท็บ และตัวควบคุมหน้าแอดมิน

เปิดใช้งานผ่านเว็บเซิร์ฟเวอร์หรือ Static Hosting ที่ให้บริการไฟล์ทั้งโฟลเดอร์ เนื่องจากหน้าแอดมินโหลดแท็บด้วย `fetch()` และไม่ทำงานเมื่อเปิดเป็น `file://`.

## เข้าสู่ระบบแอดมิน

หน้า `admin.html` และ API สำหรับอ่าน/แก้ไขข้อมูลแอดมินต้องผ่านการยืนยันตัวตนของ Apps Script ก่อนใช้งาน เพิ่ม `ADMIN_USERNAME` และ `ADMIN_PASSWORD` เป็น Script Properties แยกกันใน **Apps Script > Project Settings > Script Properties** โดยใช้รหัสผ่านที่คาดเดายากและไม่ใส่ข้อมูลรับรองไว้ในไฟล์ของโปรเจกต์ จำกัดสิทธิ์ผู้แก้ไข Apps Script เฉพาะผู้ที่ได้รับอนุญาต จากนั้นอัปเดต deployment ของ Apps Script Web App ให้ใช้โค้ดเวอร์ชันล่าสุด

การใส่ข้อมูลรับรองผิดครบ 3 ครั้งจะล็อกการเข้าสู่ระบบเป็นเวลา 20 นาที การเลือก “จำฉันไว้ในอุปกรณ์นี้” จะเก็บ session token ใน `localStorage` นานสูงสุด 30 วัน; เมื่อไม่เลือก จะเก็บใน `sessionStorage` และ token มีอายุสูงสุด 12 ชั่วโมง ปุ่มออกจากระบบจะล้าง token ในอุปกรณ์ทันทีและเพิกถอนบนเซิร์ฟเวอร์เมื่อเชื่อมต่อได้ ส่วนคำสั่งสร้าง/แก้ไข/ยกเลิกออเดอร์จากหน้าลูกค้ายังคงเป็น API สาธารณะตามการทำงานปกติ

## ราคาและการชำระเงิน

กำหนดราคาต่อหน่วยในแท็บแยกจัดตามร้าน ระบบจำราคาล่าสุดต่อร้านและสินค้าไว้ใน `localStorage` และบันทึกราคา ยอดรวม และเวลาส่งใบส่งของในชีต `Orders` ผ่าน Apps Script คอลัมน์ `UnitPrices`, `TotalAmount` และ `InvoiceSentAt`; สถานะชำระเงินใช้คอลัมน์ `Payment` ระบบจะเพิ่มหัวคอลัมน์ที่ขาดให้อัตโนมัติเมื่อมีการบันทึกครั้งแรก หลังแก้ `Code.gs` ต้องอัปเดต deployment ของ Apps Script Web App ให้ใช้เวอร์ชันล่าสุดด้วย

ในแท็บแยกจัดตามร้าน แอดมินใส่ราคาต่อหน่วยและดูยอดต่อรายการ/ยอดรวมแบบทันทีได้ ก่อนส่งใบส่งของต้องยืนยันรายการที่ไม่ได้ติ๊กจัด ซึ่งจะถูกบันทึกเป็นจำนวนและยอดเงินศูนย์ เมื่อติดใบส่งของแล้วการ์ดจะล็อกการแก้ไขและแสดงเวลาส่ง แอดมินสามารถปลดล็อกเพื่อแก้ไขและส่งใบส่งของใหม่ได้ หากแอดมินปรับจำนวนผ่านช่องทางแก้ไขออเดอร์ ระบบจะล้างข้อมูลใบส่งของเดิมและต้องบันทึกราคาใหม่อีกครั้ง

หน้าลูกค้าแสดงยอดค้างชำระสะสมจากประวัติทุกบิลที่ยังไม่ยกเลิกและมีมูลค่ามากกว่าศูนย์ โดยพับรายละเอียดไว้เป็นค่าเริ่มต้น ส่วนหน้าแอดมิน > ระบบหลังบ้าน > ประวัติร้านค้า ใช้ดูบิลย้อนหลังและเปลี่ยนสถานะชำระเงินรายบิลได้

## แก้ไข/ยกเลิกออเดอร์และเวลาตัดรอบ

ลูกค้าสามารถแก้ไขหรือยกเลิกออเดอร์ของรอบวันที่กำลังสั่งได้จากการ์ดสรุปออเดอร์ ตราบใดที่ยังไม่ถึงเวลาตัดรอบและแอดมินยังไม่ได้เปลี่ยนสถานะเป็น `จัดแล้ว` แอดมินตั้งเวลาตัดรอบ (เวลาไทย) ได้ในโหมดระบบหลังบ้าน > ตั้งค่า ค่าเริ่มต้นคือ `00:00`; Apps Script จะสร้างชีต `Settings` และบันทึกค่า `cutoffTime` ให้อัตโนมัติ การอัปเดตออเดอร์จะคง `OrderId` เดิมและรีเซ็ตราคา/ยอดรวมเพื่อให้แอดมินคิดยอดใหม่
