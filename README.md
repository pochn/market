# ตลาดเช้าแม่ทิพย์

## โครงสร้าง

- `index.html` หน้าสั่งซื้อของลูกค้า รองรับลิงก์ร้าน `?id=s_xxxx` และลิงก์เดิม `?shop=ชื่อร้าน`
- `admin.html` แดชบอร์ดจัดการรอบตลาดและข้อมูลร้านค้า
- `admin-components/` เก็บค่าตั้งต้น สถานะ คอมโพเนนต์แท็บ และตัวควบคุมหน้าแอดมิน

เปิดใช้งานผ่านเว็บเซิร์ฟเวอร์หรือ Static Hosting ที่ให้บริการไฟล์ทั้งโฟลเดอร์ เนื่องจากหน้าแอดมินโหลดแท็บด้วย `fetch()` และไม่ทำงานเมื่อเปิดเป็น `file://`.

## ราคาและการชำระเงิน

กำหนดราคาต่อหน่วยในแท็บแยกจัดตามร้าน ระบบจำราคาล่าสุดต่อร้านและสินค้าไว้ใน `localStorage` และบันทึกข้อมูลราคากับยอดรวมไว้ในชีต `Orders` ผ่าน Apps Script คอลัมน์ `UnitPrices` และ `TotalAmount`; สถานะชำระเงินใช้คอลัมน์ `Payment` ระบบจะเพิ่มหัวคอลัมน์ที่ขาดให้อัตโนมัติเมื่อมีการบันทึกครั้งแรก หลังแก้ `Code.gs` ต้องอัปเดต deployment ของ Apps Script Web App ให้ใช้เวอร์ชันล่าสุดด้วย
